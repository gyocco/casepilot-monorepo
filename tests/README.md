# Tests transversales

Esta carpeta contiene pruebas que cruzan límites del monorepo:

- `e2e/` para recorridos completos de web, mobile y servicios;
- `integration/` para servicios, adaptadores y contratos;
- `performance/` para mediciones reproducibles;
- `architecture/` para reglas de dependencias y estructura.

Las pruebas unitarias estrechamente ligadas a una librería pueden vivir junto a su código.
