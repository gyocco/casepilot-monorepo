# CasePilot Web

Frontend base built with React, Vite, Ionic React and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

The app runs at `http://localhost:5173` by default.

## Commands

```bash
npm run build   # Type-check and create a production build
npm run lint    # Run Oxlint
npm run preview # Preview the production build locally
```

## Local Supabase

From the repository root, make sure Docker is running and execute:

```bash
supabase start
```

The local Supabase configuration lives in `../../supabase`.
