# 07 — Project management

Contiene información de planificación y seguimiento que ayude a coordinar el trabajo sin convertirse en una copia del gestor de tareas.

## Documentos

- [Roadmap inicial](roadmap.md)
- [Línea base de entrega y evolución documental](delivery-baseline.md)

## Incluir

- roadmap y objetivos por etapa;
- hitos, entregables y criterios de salida;
- decisiones de alcance y riesgos conocidos;
- notas de lanzamiento o cambios relevantes.

Los tickets operativos deben permanecer en la herramienta de gestión correspondiente. Aquí se conserva el contexto que el equipo necesita consultar a largo plazo.
