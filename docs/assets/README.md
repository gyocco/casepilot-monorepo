# Assets documentales

Contiene imágenes, diagramas exportados y otros recursos estáticos usados por la documentación.

- Usar nombres descriptivos en minúsculas con guiones.
- Mantener el archivo fuente editable cuando sea posible y enlazarlo desde el documento que lo usa.
- Optimizar imágenes sin sacrificar la legibilidad.
- No almacenar secretos, capturas con datos personales ni artefactos generados sin una referencia documental.
