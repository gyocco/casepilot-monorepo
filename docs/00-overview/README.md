# 00 — Overview

Contiene el contexto que permite entender CasePilot sin leer el código.

## Incluir

- resumen del producto y del problema que resuelve;
- glosario de términos del dominio;
- mapa de sistemas, aplicaciones y actores;
- visión general de los entornos y dependencias externas.

## No incluir

No dupliques aquí los detalles de implementación de un paquete ni las instrucciones operativas paso a paso. Enlaza a `02-architecture/`, `03-development/` o `04-operations/` según corresponda.

El mapa físico del repositorio se mantiene en el [README.md de la raíz](../../README.md).
