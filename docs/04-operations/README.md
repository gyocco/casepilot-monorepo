# 04 — Operations

Documenta cómo se despliega, supervisa y mantiene CasePilot en cada entorno.

## Documento base

- [Línea base de entornos y releases](operations-baseline.md)

## Incluir

- inventario de entornos y diferencias entre ellos;
- despliegues, migraciones y rollback;
- observabilidad, alertas y métricas;
- runbooks de incidentes y tareas de mantenimiento;
- backups, recuperación y rotación de secretos.

Nunca incluyas credenciales reales. Usa nombres de variables y referencias al gestor de secretos correspondiente.
