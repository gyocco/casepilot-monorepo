# 02 — Architecture

Describe cómo está construido el sistema y cómo se relacionan sus partes.

## Incluir

- diagramas de contexto, contenedores y flujos;
- responsabilidades de `apps/`, `packages/` y `supabase/`;
- modelo de datos, políticas de acceso y límites de seguridad;
- integraciones externas, eventos y contratos entre módulos;
- decisiones de escalabilidad, rendimiento y resiliencia.

Los diagramas editables y sus imágenes exportadas deben seguir las reglas de `assets/`. Las decisiones puntuales y fechadas se registran en `06-decisions/`.
