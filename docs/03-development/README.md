# 03 — Development

Reúne las instrucciones necesarias para instalar, desarrollar y validar el proyecto localmente.

## Incluir

- requisitos de herramientas y versiones;
- instalación de dependencias y variables de entorno de ejemplo;
- comandos de desarrollo, lint, build y pruebas;
- convenciones de código, ramas y revisiones;
- guía para crear una app o paquete nuevo.

Los comandos exclusivos de una aplicación deben mantenerse en el `README.md` de esa aplicación y enlazarse desde aquí cuando formen parte del flujo general.
