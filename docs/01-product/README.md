# 01 — Product

Documenta el comportamiento esperado del producto desde la perspectiva de usuarios y negocio.

## Incluir

- objetivos, alcance y fuera de alcance;
- personas, roles y permisos esperados;
- casos de uso y flujos principales;
- requisitos funcionales y no funcionales;
- criterios de aceptación y reglas del dominio.

Las decisiones de implementación deben enlazar a `02-architecture/` o `06-decisions/` en lugar de mezclarse con los requisitos.
